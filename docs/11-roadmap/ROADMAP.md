# Roadmap

The [development plan](DEVELOPMENT-PLAN.md) is the authoritative dependency queue. Strategic phases are delivery groups, not a second task numbering system.

1. Checked contracts and safe engine foundation: workspace, persistence, hashes, gates, detection, doctor and CLI.
2. Measured source behavior: parser/adapter extraction, operational roots, isolation, complete observations, cases and comparators.
3. Verified first slice: capability plan, Gate 2, safe target publication and independent Laravel execution.
4. Reference application: auth/session continuity, CRUD/effects/views/files, repair/mission/MCP, performance and Gate 3 runbooks.
5. Release evidence: privacy-reviewed learning/Skill, two clients, native platform checks, security/recovery and supported capability matrix.
6. Extensions: additional targets/sources through the same IR, chosen by documented customer demand and tested capability intersections.

CLI/verification/gates precede generation; they are not postponed until after target code. Optional global learning and additional adapters cannot block baseline deterministic operation. No dates or team capacity are assumed; estimate tasks after the first fixture measurements.
