# Terminology usage

[GLOSSARY](../00-vision/GLOSSARY.md) indexes names and canonical semantic owners. A workflow is a bounded scenario graph/stateful sequence, not necessarily linear. A route is HTTP dispatch; an operation can have HTTP/CLI/cron/event entrypoints. A migrated file is implementation within a behavioral unit, not the unit itself. PASS/MISMATCH/UNKNOWN are verifier results; unsupported/blocking capability reasons do not introduce successful verdicts. Maturity/tier/progress/verdict/approval remain distinct.
